### Meni Gottesman

**Selected public work**

- [nutritionist](https://github.com/meni-gottesman/nutritionist): an in-browser nutrition calculator that turns a few inputs into personalized daily targets
- [satiety-explorer](https://github.com/meni-gottesman/satiety-explorer): an interactive graph of foods scored by fullness per calorie

Most of my recent work (at Berkeley Lab) lives in private repositories.
